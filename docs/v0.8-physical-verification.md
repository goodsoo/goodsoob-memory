# V0.8 물리 검증 체크리스트

V0.8 (PWA local-first) 는 main 에 머지 완료(PR #88). 아래는 리뷰·자동 테스트로 확인 불가능한 **실기 검증** 항목이다. 코드는 전부 main 에 있고, 두 맥·폰 실물에서만 확인된다.

전체 설계: `docs/designs/pwa-local-first-migration.md`

## ① 폰 PWA HTTPS 설치

tailscale serve 는 활성 확인됨(`https://angel-pro.tail8c78d6.ts.net:10000` → `127.0.0.1:7080` 프록시, ts.net Let's Encrypt cert).

- [ ] 폰에 Tailscale 앱 로그인(ham.goodsoo) + VPN 연결
- [ ] Safari(Chrome 아님)에서 `https://angel-pro.tail8c78d6.ts.net:10000` 접속 — IP:포트 아니라 hostname 이라야 cert 일치
- [ ] 공유 버튼(⬆︎) → "홈 화면에 추가" → 홈 아이콘("짱수메모리")으로 standalone 실행

통과 기준: 폰에서 vault 열람·메모 CRUD 정상. Pro 서버 sleep/종료 시 접속 끊김 안내 정상.

## ② 두 맥 fallback E2E + PRO_HEALTH_URL 실값

- [ ] `deploy/air-fallback.sh` 의 `PRO_HEALTH_URL` 을 Pro 실주소로 설정 (예: `http://angel-pro...:7080/api/health`)
- [ ] air 맥에 `deploy/com.goodsoob.memory.air.plist` 설치(launchd)
- [ ] Pro 서버 내림 → air 가 헬스체크로 감지 → air 서버 자동 기동 확인

통과 기준: Pro 다운 시에만 air 기동(Pro 살아있으면 air 안 뜸 = **이중 writer 방지**). 폰/브라우저가 air 로 fallback 접속.

## ③ Pro 복귀 시 air 자동 종료

현재 수동 `launchctl unload`. 자동화는 미구현.

- [ ] Pro 서버 복귀 후 air 서버가 자동 종료되는지 (미구현이면 수동 unload)
- [ ] 겹침 구간(둘 다 writer)에서 vault git 이 무손실 흡수하는지 확인

통과 기준: 겹침 없이 단일 writer 유지. 겹쳐도 데이터 유실 0.

## ④ iOS 실기 오프라인 / eviction E2E

- [ ] 폰 PWA 비행기모드에서 메모 쓰기 → outbox(IndexedDB) 큐잉 → 재연결 시 자동 flush 확인
- [ ] iOS Safari 저장소 eviction(장기 미사용 축출) 후 재접속 → 서버에서 재동기화 확인

통과 기준: 오프라인 쓰기 유실 0. eviction 후 데이터 복구.
