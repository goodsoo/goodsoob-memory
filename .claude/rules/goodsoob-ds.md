# goodsoob 디자인 시스템 규칙 (UI 작업 전 필독)

UI 파일을 만들거나 고치기 전에 **`node_modules/@goodsoob/ds/docs/components.md` 를 Read 로 먼저 읽고** 그 규칙대로 작업한다 (컴포넌트 선택·소비 방식·토큰 어휘). 이 세션에서 이미 읽었으면 다시 읽지 않는다.

- 이 파일은 포인터다. 규칙 본문은 설치된 `@goodsoob/ds` 패키지에 있다 (canonical 이 repo 밖이라 Claude Code 가 심링크 규칙을 불러오지 않음 → 직접 읽게 한다).
- 파일이 없으면 `npm install` 이 안 된 것이다. 그때는 canonical `goodsoob-design-system/docs/components.md` 를 읽는다.
